# 課題0507 AIコードレビュー(成績判定)

次の仕様の成績判定プログラムを，AIに書かせたという設定のコードが `main.c` にある．**誤りが3つある．**

| 入力 | 表示 |
|---|---|
| 101 以上 | NG |
| 90 〜 100 | AA |
| 80 〜 89 | A |
| 70 〜 79 | B |
| 60 〜 69 | C |
| 1 〜 59 | D |
| 0 | / (スラッシュ) |
| 負の数 | NG |

## 課題
1. `main.c` を直して仕様どおりにせよ．
2. 元のコードの誤りを再現する入力を `bugs.txt` に1行1つ書け(3つ以上)．**3種類の誤り** すべてを見つけること．
   (どの入力が怪しいかは **境界値** を調べるとよい．各区間の端の値を試すこと．)

ヒント: `else if` は上から順に調べ，最初に成り立った所で止まる．条件の順番と，`>` か `>=` かに注意せよ．

## 提出するファイル
- `main.c`
- `bugs.txt`
- `ai_log.txt`

## 採点について
- push すると GitHub Actions が自動採点します。結果は Actions のログと、フィードバック用の Pull Request に出ます。
- 採点は **プログラムを実行した結果** で行います。何度でも push して再採点できます。
- `ai_log.txt`(AI利用ログ)も採点対象です(10点)。AIを使ってもかまいません。ただし **AIの答えを自分で確かめること** が課題の目的です。
